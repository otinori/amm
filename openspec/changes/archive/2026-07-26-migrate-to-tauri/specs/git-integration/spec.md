## ADDED Requirements

### Requirement: status 出力の非ASCIIファイル名表示
`git status --short` の呼び出しは、ファイル名に含まれる非ASCII文字（日本語等）をエスケープ表示させない設定（`core.quotepath=false` 相当）で実行しなければならない (SHALL)。

#### Scenario: 日本語ファイル名を含む status 出力
- **WHEN** 非ASCII文字を含むファイル名の変更があるリポジトリで status を取得する
- **THEN** ユーザーに提示される status テキストは当該ファイル名をエスケープせずそのまま表示する

### Requirement: 未プッシュ確認の既定アクション
未プッシュコミットの確認ダイアログにおいて、ユーザーが追加の選択操作なしに確定操作（Enter 相当）を行った場合、既定のアクションは「プッシュする」でなければならない (SHALL)。

#### Scenario: 確定操作の既定アクションはプッシュ
- **WHEN** 未プッシュ確認ダイアログが表示された状態で、ユーザーが選択肢を明示的に選ばずに既定の確定操作を行う
- **THEN** amm は push を実行する（スキップとして扱ってはならない）
